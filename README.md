## 购买阿姆斯特丹 VPS 前要检查什么？

### 1. 先确认机房库存

官网会列出 Amsterdam Netherlands 作为可选位置，但最终能否购买仍取决于套餐和库存。进入订单页面后，要确认位置选择框中是否仍然显示 Amsterdam，以及当前规格是否可以下单。

### 2. 看清计费周期

20G、40G 的低价主要来自年付或半年付。80G 以上虽然支持月付，但长期预付价格与月付价格并不完全相同。建议按照项目生命周期计算总成本，而不是只比较标价中的“每月”数字。

### 3. 分清带宽和端口速度

例如 80G 套餐包含 3 TB/月流量和 1 Gbps 端口。3 TB 是月度传输额度，1 Gbps 是网络端口速度，两者不是一回事。端口更快不代表每月可用流量无限增加。

### 4. 提前规划备份

官方购物车列出了自动备份和快照等功能，但重要业务仍不应该只依赖主机商内部备份。至少应把数据库、网站文件和配置文件定期复制到另一台服务器或对象存储中。

### 5. 检查应用是否符合服务条款

条款禁止垃圾邮件、端口扫描、挖矿、开放代理、Tor 出口节点、未经授权的版权内容分发、恶意软件、某些金融平台和数据抓取等活动。

如果你的项目涉及大量爬虫、邮件群发、代理出口或高持续 CPU 任务，购买前应先确认是否符合规定。否则价格再低，也不适合当作长期生产环境。
